CLOUDFLARE PAGES DEPLOY
=======================

Domain: https://pdtg-transport-punjab.com/

This project is a static site (HTML + Supabase). Cloudflare Pages is the
correct host — no PHP/MySQL needed on the server.

1) In Cloudflare Pages, create/connect the project and deploy these files
   from the site root:
   - index.html          (admin: issue / edit / verify permits)
   - permit.html         (public permit view via QR)
   - verify.html         (public MTMIS-style reg-no check)
   - SETUP.txt           (optional)

   Do not add a _redirects file that rewrites paths to *.html — Cloudflare
   already strips .html and those rules cause deploy error 100324.

2) Custom domain
   - Pages → Custom domains → add pdtg-transport-punjab.com
   - Also add www if you use it, and redirect www → apex (or vice versa)

3) Login at:
   https://pdtg-transport-punjab.com/

4) Public links (after deploy):
   - Permit:  https://pdtg-transport-punjab.com/permit.html?id=PERMIT_ID
   - Verify:  https://pdtg-transport-punjab.com/verify.html
   - Verify:  https://pdtg-transport-punjab.com/verify.html?reg=LEB-1234

5) Official Excise MTMIS (ownership / token tax — separate system):
   https://mtmis.excise.punjab.gov.pk

Notes
-----
- QR codes always point at https://pdtg-transport-punjab.com (even on
  Cloudflare preview URLs), so scanned links stay on production.
- Database / auth stay on Supabase (configured inside index.html and
  permit.html). Cloudflare Pages only serves the static files.
- If you later move off Supabase to PHP+MySQL, you need different
  hosting (cPanel/VPS) — Pages cannot run PHP.
