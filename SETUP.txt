CLOUDFLARE PAGES DEPLOY
=======================

Domain: https://pdtg-transport-punjab.com/

This project is a static site (HTML + Supabase). Cloudflare Pages is the
correct host — no PHP/MySQL needed on the server.

1) In Cloudflare Pages, create/connect the project and deploy these files
   from the site root:
   - index.html          (public homepage — like a guide/landing page)
   - verify.html         (public MTMIS-style reg-no check, no login)
   - permit.html         (public permit view via QR)
   - admin.html          (staff login: issue / edit / verify permits)
   - SETUP.txt           (optional)

   Do not add a _redirects file that rewrites paths to *.html — Cloudflare
   already strips .html and those rules cause deploy error 100324.
