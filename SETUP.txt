Public Vehicle Hub PK guides were moved out to a separate repository.
Transfer branch (Vehicle Hub files at repo root):
  https://github.com/digitalprint077-lang/punjab-route-permit/tree/export/vehicle-hub-pk

Create a new empty GitHub repo (example name: vehicle-hub-pk), then push that branch:
  git clone https://github.com/digitalprint077-lang/punjab-route-permit.git
  cd punjab-route-permit
  git checkout export/vehicle-hub-pk
  git remote add hub https://github.com/digitalprint077-lang/YOUR-NEW-REPO.git
  git push -u hub export/vehicle-hub-pk:main
