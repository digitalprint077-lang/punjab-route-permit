Vehicle Hub PK — Android app (native UI)
========================================

Modern native Android app for Vehicle Hub PK
(https://vehiclehubpk.com/).

Features
--------
- Native Home / Licence / Provinces / Guides / More
- Information page before every official government website
- Government Sources screen (More → Government Sources)
- Driving licence portals (Punjab, Sindh, Islamabad, KPK, Balochistan, Gilgit)
- Independent Notice + affiliation disclaimer
- Opens official sites in Chrome Custom Tabs / browser (no WebView)
- Generic Material icons (no government seals/emblems)
- Vehicle Hub PK branding (green hub-wheel logo)
- Green theme (#038B45) + Outfit font
- Animated bottom tabs + screen transitions
- Responsive layouts
- Google AdMob banner (real unit IDs)
- Signed release APK + AAB

Build
-----
  cd android
  ./gradlew assembleRelease bundleRelease
  cp app/build/outputs/apk/release/app-release.apk dist/VehicleHubPK-v1.3.3-release.apk
  cp app/build/outputs/bundle/release/app-release.aab dist/VehicleHubPK-v1.3.3-release.aab

Package
-------
  applicationId: com.vehiclehubpk.app
  display name: Vehicle Hub PK
  versionName: 1.3.3
  versionCode: 13
