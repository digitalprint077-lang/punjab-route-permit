Pak Excise Info — Android app (native UI)
=========================================

Modern native Android app for the Pak Excise Info website.
The website itself is not modified.

Features
--------
- Native Home with brand hero, category icons, and province cards
- Provinces tab → province detail with service category icons
- Services tab with icon categories + optional guide links
- More tab (website, about, contact, privacy)
- Tapping a category opens the official portal (Chrome Custom Tabs)

Open in Android Studio
----------------------
Open the `android/` folder, sync Gradle, Run ▶

Build debug APK
---------------
  cd android
  ./gradlew assembleDebug
  cp app/build/outputs/apk/debug/app-debug.apk dist/PakExciseInfo-debug.apk

Prebuilt download
-----------------
  android/dist/PakExciseInfo-debug.apk

Package
-------
  applicationId: com.pakexciseinfo.app
  Site: https://pdtg-transport-punjab.com/
