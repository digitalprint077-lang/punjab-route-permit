Vehicle Hub PK — Android app (native UI)
========================================

Modern native Android app for Vehicle Hub PK
(https://pdtg-transport-punjab.com/).

Features
--------
- Native Home / Provinces / Services / More matching the live site
- Vehicle Hub PK branding (green hub-wheel logo from logo.svg)
- Green theme (#038B45) + Outfit font
- Gilgit Excise included with other provinces
- Responsive layouts (phone / tablet column counts)
- Entrance + press animations
- Offline-aware portal opening (Custom Tabs)
- Remote/updatable service URLs via app-config.json
- Google AdMob banner (real unit IDs)
- Search on Provinces / Services
- Signed release APK + AAB

Open in Android Studio
----------------------
Open the `android/` folder, sync Gradle, Run ▶

Build debug / release
---------------------
  cd android
  ./gradlew assembleRelease bundleRelease
  cp app/build/outputs/apk/release/app-release.apk dist/PakExciseInfo-vX.Y.Z-release.apk
  cp app/build/outputs/bundle/release/app-release.aab dist/PakExciseInfo-vX.Y.Z-release.aab

AdMob ads
---------
Config: app/src/main/java/com/pakexciseinfo/app/ads/AdsConfig.kt
Play Store release uses REAL AdMob IDs (useTestAds = false).

Banner shows above the bottom navigation on all main tabs.

Updatable portal URLs
---------------------
Bundled: android/app/src/main/assets/app-config.json
Remote:  https://pdtg-transport-punjab.com/app-config.json
