Pak Excise Info — Android app (native UI)
=========================================

Modern native Android app for the Pak Excise Info website.
Website pages are unchanged except optional app-config.json for live URL updates.

Features
--------
- Native Home / Provinces / Services / More with icons
- Offline-aware portal opening (Custom Tabs)
- Remote/updatable service URLs via app-config.json
- Optional Firebase Crashlytics
- Google AdMob banner ads (test IDs by default)
- Search on Provinces / Services
- Signed release build support

Open in Android Studio
----------------------
Open the `android/` folder, sync Gradle, Run ▶

Build debug / release APK
-------------------------
  cd android
  ./gradlew assembleDebug assembleRelease
  cp app/build/outputs/apk/release/app-release.apk dist/PakExciseInfo-release.apk

AdMob ads
---------
Config file: app/src/main/java/com/pakexciseinfo/app/ads/AdsConfig.kt

IMPORTANT: Real AdMob units often show NOTHING (NO_FILL / code 3) until:
- AdMob payment/account is verified
- App is linked / published on Play Store
- AdMob app status shows Ready (can take hours–days)

Right now useTestAds = true so Google TEST banners always appear and prove
the ad slot works. Your real IDs are already saved in AdsConfig.

Before Play Store release (when AdMob status is Ready):
1) In AdsConfig.kt set useTestAds = false
2) In app/build.gradle.kts set admobAppId = AdsConfig.realAppId
3) Rebuild

Banner shows above the bottom navigation on all main tabs.

Also update your privacy policy to mention AdMob, and complete
Play Console Ads + Data safety forms before publishing.

Updatable portal URLs
---------------------
Bundled: android/app/src/main/assets/app-config.json
Remote:  https://pdtg-transport-punjab.com/app-config.json

Crashlytics (optional)
----------------------
1) Create a Firebase Android app for package com.pakexciseinfo.app
2) Download google-services.json into android/app/
3) Rebuild — Crashlytics enables automatically
